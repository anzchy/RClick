# RClick 2.3.5

Release date: 2026-11-24.

## What's new

- Cut selected Finder items, then use Paste (move here) to move them within the same volume. Name collisions get numbered names; partial failures retain retryable items.
- Undo last move restores the latest same-volume Paste for up to 24 hours, including after relaunch. Replaced items and changed original folders are refused.
- Keep several templates for each New File type, reorder them in Settings and choose them from Finder submenus. Valid DOCX, PPTX and XLSX templates are included. Office and iWork formats require a valid template; plain text/code types can use Blank.
- Export and import settings, copy multiple paths or file names as plain text, and use app presets and per-app visibility controls.
- Finder messages use authenticated IPC with replay protection. File-action diagnostics omit selected paths and names, reporting safe counts and outcomes instead.
- More reliable same-volume Paste recovery, custom extensions, settings import, update installation and Finder reconnection.

## Behavior and compatibility

The new app identity is `cn.anzchy.RClick`, with a separate App Group. **Settings and folder grants of the upstream app are not migrated.** Configure the fork and grant access to folders again.

**Cut, Paste and Undo are opt-in and default off.** Enable Cut & Paste in Settings to use these actions; Undo appears only when eligible history is available. Cross-volume Paste is not available in this release (#10).

The update checker reads releases from `anzchy/RClick`, including prereleases. A higher numeric version marked as a prerelease is still offered as an update. The release tag is `v2.3.5`; no suffix is used. The JSON custom-menu layout has been removed; configure menu contents in Settings.

RClick requires macOS 15.6 or later; the current release workflow builds for Apple silicon (arm64).

This is a GPL-3.0 modified version of RClick by wflixu; third-party template notices are retained in `THIRD_PARTY_NOTICES.md`.

Known unverified:

- Real Trash, alias/cloud-provider destinations and destination/source swap races; quit during a move, interrupted recovery and Undo expiry.
- Undo hidden before any Paste (previous history was present), Cut toolbar, protected-folder warning and Copy Path into a terminal.
- PPTX Quick Look, Word/Pages opening, upgraded-store menus and Blank switched off with one template.
- Cross-volume Paste is unavailable; signed release artifact and clean-machine checks remain unverified.

Checked on the draft artifact by the owner before publication: NOT VERIFIED (clean-machine install, extension enablement and #40: first v2 IPC key creation, prompt-free extension read and authenticated click).

Five benign IPC freshness rejections were observed without visible effect (#82). After a zero-success Paste, the older journal entry remains offered. Undo is single-shot even after partial restoration (#79).

Cross-volume Paste is excluded from the release gate. Pinning directory descriptors narrows ancestor-swap races; a pinned folder relocated into Trash after the last location check remains a known limitation. Undo is a single latest-move record and may skip changed items; interrupted Paste recovery can replace older Undo history. Further IPC hardening is tracked in #41.
