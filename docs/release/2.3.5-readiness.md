Extension Info.plist is generated with the target marketing version as CFBundleShortVersionString. The extension should ship at the app's marketing version; no application code compares app and extension marketing versions. `SingleInstanceGuard` compares **app copies** using CFBundleShortVersionString and chooses the higher version, then later launch, then lower PID. It bypasses termination for hosted tests. This does not enforce extension agreement. A runtime app/extension marketing-version mismatch alone triggers no rejection: authenticated wire/session/payload compatibility governs IPC; stale Finder registration can leave an older extension running.

`RClickApp.swift:39–41` constructs UpdateManager from the app short version. `Updater.swift:152–156` reads the fork releases list; drafts are excluded, prereleases included, highest version wins. Test-host app builds use 2.3.5; the separate test bundle's 1.0 does not affect that check. Local 2.3.5 builds will not offer an equal-version release as a newer update.

## Version agreement check

No existing app/extension version-agreement assertion was found. This repository check asserts agreement per configuration and preserves test-target version 1.0 without changing Swift or agent tooling. Run at the repo root; optionally pass the expected release version as the shell's first argument (for example, run this block in `sh -s -- 2.3.5`). With no argument it checks agreement only; release readiness must also run it with expected version 2.3.5 so an agreed-but-stale pair fails.

```sh
python3 - "${1:-}" <<'PYCODE'
import plistlib, subprocess, sys
expected = sys.argv[1] or None
project = plistlib.loads(subprocess.check_output(['plutil', '-convert', 'xml1', '-o', '-', 'RClick.xcodeproj/project.pbxproj']))['objects']
versions = {}
for target in project.values():
    if target.get('isa') == 'PBXNativeTarget' and target.get('name') in ('RClick', 'FinderSyncExt', 'RClickTests'):
        configs = project[target['buildConfigurationList']]['buildConfigurations']
        versions[target['name']] = {project[c]['name']: project[c]['buildSettings']['MARKETING_VERSION'] for c in configs}
assert set(versions) == {'RClick', 'FinderSyncExt', 'RClickTests'}, versions
assert all(set(configs) == {'Debug', 'Release'} for configs in versions.values()), versions
for config in ('Debug', 'Release'):
    app, extension = (versions[name][config] for name in ('RClick', 'FinderSyncExt'))
    assert app == extension, f'{config}: app {app} != extension {extension}'
    assert expected is None or app == expected, f'{config}: expected {expected}, got {app}'
    assert versions['RClickTests'][config] == '1.0', f'{config}: test bundle must stay 1.0'
print(f'PASS app/extension versions agree per configuration; tests 1.0; expected={expected or "not specified"}')
PYCODE
```
